Zorg voor meer banen via social return en sociaal ondernemen

MotieRachid Guernaoui7 juli 2022

De raad van de gemeente Den Haag, in vergadering bijeen op 7 juli 2022, ter bespreking van de
Programmarekening 2021.

Constaterende dat,
Bij opdrachten vanaf € 231.000 geldt dat de opdrachtnemer 5% van de inschrijfsom
(aanneemsom) aan social return besteedt;
Opdrachtnemers (de bedrijven die een aanbesteding hebben gewonnen) de social return eis
kunnen invullen met een baan bij het bedrijf zelf maar ook via een baan bij een erkende sociaal
ondernemer;
opdrachten van de gemeente kunnen worden gerealiseerd via een aanbesteding maar ook via
een voorbehouden aanbesteding (rechtstreekse gunning) aan een sociaal ondernemer;
de banen die via social return of via sociaal ondernemen, voor bijstandgerechtigden, niet
worden bijgehouden en daardoor ook niet openbaar kunnen worden gemaakt;
dat niet voor alle contracten duidelijk is hoe social return concreet wordt ingevuld en/of
afgekocht;
dat openbaarheid zorgt voor extra stimulans voor social return en sociaal ondernemerschap en
daardoor voor meer banen voor uitkeringsgerechtigden.

Verzoekt het college,
Om alle gerealiseerde banen via social return en sociaal ondernemerschap inzichtelijk te
maken zodat deze openbaar kunnen worden gemaakt via de website van de gemeente.

En gaat over tot de orde van de dag.

Rachid Guernaoui
Hart voor Den Haag
